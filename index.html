Planning des machines de soudage

Charge = encours (quantité lancée − sortie soudage) × temps de soudage (colonne TPS du fichier Machine). Pour les articles fantômes, la date de soudage est celle d’engagement moins 1 jour ouvré (J-1, dimanche exclu). Quand une machine dépasse sa capacité, les articles ayant une 2ᵉ machine dans le fichier Machine sont scindés automatiquement : la machine 1 est complétée, le reste va sur la machine 2.
